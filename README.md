## 独立服务器什么时候值得上

VPS 是共享物理机资源的虚拟实例，独立服务器整台机器归你，包括全部 CPU 核心、内存通道和硬盘 IO。Lightlayer 最低一档 150 美元/月，双路 E5-2660、16 核 64GB、1TB SSD、Premium 50Mbps 不限流量、5 个 IPv4。

这档配置跑一个日 IP 几万的外贸站或中型数据库够了。判断要不要从 VPS 升级，看三个信号：磁盘 IO 长期打满（NVMe 云主机也会被同宿主机邻居影响）、内存不够用只能靠 swap 撑着、需要自己装内核模块或特殊网络配置而虚拟化层不允许。

150 美元这档的 CPU 是十年前的 E5-2660 v1 世代，单核性能弱。如果你的业务吃单核（比如 PHP 老版本应用、单线程任务队列），64 核的 EPYC 7502 那档 900 美元/月更合适；如果只是要多核并行跑编译、渲染、批处理，E5-2660 双路的 16 核 32 线程在这个价位不亏。

## 常见问题

**国外服务器租用需要备案吗？**
不需要。服务器在境外，不走国内 ICP 备案流程。域名本身如果用国内注册商，实名认证还是要做，这和服务器备案是两件事。

**VPS 和独立服务器怎么选？**
先买 VPS。VPS 开通快、可以随时换配置、月付几美元试错成本低。跑满三个月，确认业务模型成立、资源确实不够了，再迁独立服务器。反过来先买独服再降级，钱白花。

**同样 4 美元，我该买 Premium 还是 Global？**
看访客在哪。中国大陆访客为主，Premium 的 20Mbps 比 Global 的 100Mbps 体验好，因为延迟低、晚高峰稳。访客在海外，Global 的端口大五倍，价格一样。

**香港 5 美元那档能跑得动外贸站吗？**
文字为主的企业站、产品目录站没问题，10Mbps 不限流量，日均几千 IP 很轻松。站里放大量高清产品视频就不够了，那种情况要么换 Global 线路，要么把视频放对象存储。

**年付能省多少？**
只有洛杉矶三条线路有独立年付方案，国际线路 29.99 美元/年最划算，比月付省 18 美元；优化线路 49.99 美元/年反而比月付贵 1.99 美元。其他机房按月付。

**能装 Windows 吗？**
可以，需要 2GB 内存以上，默认是 Linux，装 Windows 要手动切换。
